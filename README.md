# mimundo

Tienda web estática para alimentos frescos en Miraflores. Abrir `index.html` en un navegador moderno para recorrer el catálogo, filtrar productos y preparar una venta.

## Venta por correo

La acción **Grabar la venta** genera un correo dirigido a `richardgereholliwod@gmail.com` con vendedor, productos, cantidades, precios, total y fecha. Como esta versión es solo HTML, CSS y JavaScript, usa `mailto:`: el cliente de correo del dispositivo debe estar configurado y la persona debe pulsar **Enviar**. La página no puede confirmar la entrega real de un correo sin un servidor o proveedor de envío.

## Archivos

- `index.html`: contenido y secciones.
- `styles.css`: diseño adaptable para escritorio y móvil.
- `app.js`: catálogo, filtros y carrito.
- `assets/`: ilustraciones SVG originales creadas para la tienda.
